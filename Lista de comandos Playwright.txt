Lista de comandos Playwright:

Vídeo 2:
npx playwright test - executa os testes dentro da pasta test
npx playwright test --headed - executa os testes dentro da pasta test mostrando a execução nos navegadores
npx playwright test ./tests/login.spec.js - executa apenas o login.spec.js

Vídeo 3:
test.only - executa apenas aquele teste
test.skip - não executa aquele teste

Vídeo 4:
await page.getByAltText("profile picture").first.click() - nesse caso há 2 elementos "profile picture" na página, então é necessário informar que é para clicar no primeiro (first).
